# civil-procedure-law-interpretation

民事訴訟法教材：依法條編章排列，每一課是「短動畫＋互動講義」（條文逐句讀、模擬器、六題練習）。

- 網站：https://mjib007.github.io/civil-procedure-law-interpretation/
- 總覽頁 `index.html` 由本機 `網站工具/build_index.py` 產生；新增教材時改該檔的 `NEW` 清單後重跑。
- 講義放在 `lectures/`。
- 條文依全國法規資料庫現行條文（民事訴訟法112年11月29日修正版）。

教學整理，不代替個案法律判斷。本站教材採 CC BY-NC 4.0 授權（見 LICENSE.md）：非商業使用，請標明出處。
